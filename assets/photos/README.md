# Foto Anggota Keluarga

Simpan foto anggota keluarga di folder ini, lalu rujuk dari `js/data.js`:

```js
photo: "assets/photos/oma-sri.jpg",
```

Tips:

- Gunakan gambar **persegi (1:1)** — foto ditampilkan dalam bingkai lingkaran.
- Ukuran 400×400 px sudah cukup; file besar hanya memperlambat halaman.
- Nama file sebaiknya huruf kecil tanpa spasi, mis. `om-bambang.jpg`.
- Kalau `photo` dikosongkan atau file tidak ditemukan, avatar inisial
  bergradasi otomatis dipakai sebagai pengganti.
